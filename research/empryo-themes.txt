Quick start
Link to this section
Run
/theme
, or press
Ctrl+K
and search for "theme", to open the theme picker. The app changes color as you move through the list, so you can see each theme before you choose it.
Default:
proxysoul-undertow
Link to this section
Empryo uses the ProxySoul Undertow theme by default, in both the terminal UI and the desktop app.
To follow your system's light or dark mode instead, pick
system
. It uses
proxysoul-undertow
when your system is dark and
proxysoul-undertow-light
when it is light.
To decide between light and dark, Empryo first checks your terminal's background color. If it cannot tell, it uses your operating system's setting (macOS appearance, the Windows app theme, or the GNOME color scheme). To force one, set
EMPRYO_APPEARANCE=dark
or
EMPRYO_APPEARANCE=light
.
Picking any other theme turns off the automatic switching.

Config
Link to this section
Your theme is saved for all projects in
~/.empryo/config.json
:
json
Copy
{
  "theme": {
    "name": "catppuccin",
    "transparent": true,
    "userMessageOpacity": 70,
    "diffOpacity": 30,
    "borderStrength": "strong"
  }
}
Field
Description
name
The theme id (built-in or your own)
transparent
Make the background transparent, so your terminal's own background shows through
userMessageOpacity
How solid the background of your messages is in transparent mode:
0
(clear),
30
(dim),
70
(subtle),
100
(solid)
diffOpacity
How solid the background of diffs is in transparent mode:
0
(clear),
30
(dim),
70
(subtle),
100
(solid)
borderStrength
How visible borders are:
"default"
,
"strong"
or
"op"

Key
Action
↑
/
↓
Move through themes (with live preview)
Enter
Apply the selected theme
Tab
Turn transparent mode on or off
M
Change the message background opacity
D
Change the diff background opacity
B
Change the border strength
Custom themes
Link to this section
To make your own theme, add a JSON file to
~/.empryo/themes/
:
bash
Copy
mkdir -p ~/.empryo/themes
Example
Link to this section
~/.empryo/themes/my-theme.json
:
json
Copy
{
  "_extends": "dark",
  "_label": "My Theme",
  "_description": "A custom dark theme",
  "_variant": "dark",
  "brand": "#ff6600",
  "brand-secondary": "#ff0040",
  "bg-primary": "#1a1a2e",
  "bg-elevated": "#16213e",
  "text-primary": "#e0e0e0",
  "success": "#00ff88",
  "error": "#ff4444"
}
The file name without
.json
becomes the theme id. This one is
my-theme
.

_description

_variant
"dark"
or
"light"

Legacy format
Link to this section
You can also put several themes in one file,
~/.empryo/themes.json
:
json
Copy
{
  "my-theme": {
    "_extends": "dark",
    "brand": "#ff6600"
  },
  "another-theme": {
    "_extends": "light",
    "brand": "#0066ff"
  }
}
Hot reload
Link to this section
Empryo watches your theme files. When you save a change to a custom theme, the app updates right away. You do not need to restart.
