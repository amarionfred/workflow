# Bounded role contract

Role and owner:
Question or deliverable:
Workspace/worktree and allowed write paths:
Inputs and canonical context:
Acceptance checks and evidence to return:
Actions already authorized:
Actions outside this assignment:
Time/compute limit:
Dependencies and escalation condition:
Handoff destination:

Use only roles that help this task. The coordinator owns integration and final claims. A builder returns artifacts and its checks. A verifier examines the requirement and artifact independently; a model review alone is not ground truth. A researcher returns primary sources, uncertain claims, and a discriminating experiment. Park owns taste and consequential choices not already delegated.

Separate role instructions do not create isolation. Concurrent changes need independent worktrees or disjoint files. Blind evaluation requires real access boundaries. A fresh agent in the same workspace can still see the other agent's work.
